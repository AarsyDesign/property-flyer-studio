# Property Flyer Studio

1-Click Replaceable Visual Template Generator untuk Desain Iklan Properti Instagram & Facebook Feed (Format Rasio Optimal 4:5 / 1080 x 1350 px).

## Fitur Utama
- **1-Click Image Replacer:** Ganti foto utama (fasad depan) dan 3 galeri interior/fasilitas vertikal cukup dengan klik upload atau drag-and-drop.
- **Live Text & Price Sync:** Edit nama brand, headline tipe properti, harga, lokasi, 3 poin fasilitas, CTA, dan nomor WhatsApp secara *real-time*.
- **Retina HD Export (PNG):** Tombol ekspor 1-klik dengan resolusi 3x (~1560 x 1950 px) jernih dan tajam tanpa pecah.
- **Color Theme Swatches:** Pilihan palet warna panel bawah (Pine Green, Slate Navy, Wine Crimson, Obsidian Vercel, Warm Bronze).
- **Standalone & Portable:** Cukup buka `index.html` di browser mana pun tanpa perlu dependensi rumit.
